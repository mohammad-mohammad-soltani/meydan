# Feed, compose, and media reference audit

Read-only product audit, 2026-10-04. Only this report was added. The supplied HTML is a visual reference, not trusted application code. Its inline scripts were extracted with `HTMLParser` and beautified to `/tmp/meydan-feed-reference.js`; all CSS was inspected in `/tmp/meydan-reference.css`. Neither artifact is imported by the application. Reference `M` source metadata (for example `lineNumber: 940`) identifies the original React source; CSS line numbers below identify the beautified extracted CSS. Findings are source-derived; browser screenshots and authenticated API mutations were not performed by this audit.

AGENTS.md and installed Next 16.3.4 `node_modules/next/dist/docs/01-app/01-getting-started/03-layouts-and-pages.md` were read. App Router promise params/searchParams and existing client/server boundaries must be retained. `app/layout.tsx:12` loads the variable `IRANSansXV.woff2`; retain this font even though the reference hardcodes Vazirmatn. Font differences alone are not defects.

## Route and reuse inventory

- `/home`: server loads `/timeline` and suggestions, client `FeedView` owns tabs, filters, pagination, likes, reposts, following, and deletion.
- `/compose`: server authentication guard, normal/quote/work mode in `ComposeView`; quotes use `/compose?quote=ID`, work mode uses `?mode=work`.
- `/videos`: **renders `ReelsView`, not `VideosView`**. The separate grid component is not the route entry point.
- `/posts/[postId]` and `/posts/[postId]/quotes`: genuine narrative and quote fetches; post detail uses `PostCard` detail variant, quote lists use timeline cards.
- `/bookmarks`, profile activity, and `/content/report-days/[date]`: reuse timeline `PostCard` (some intentionally hide actions). Changes to this component affect all of them.
- Chat attachments reuse `MediaGallery` with `tone="bubble"`; composer attachment previews use `ComposeMediaGrid`. Global media changes can affect chat geometry.
- `/drafts` uses `features/coming-soon/DraftsView`; `/podcasts` reads content service; `/screening` is a coming-soon view. They are distinct from the compose local draft and reels route.
- The entire `app` route tree was enumerated; unrelated admin, map, speaker, auth, content and chat routes are outside this report’s geometry scope and should not receive feed-specific global selectors.

## CSS cascade interpretation

The reference's JSX is not its final appearance. CSS 6180–6297 makes rose/amber/emerald/sky utility controls monochrome. Compose CSS 7094–7179 explicitly uses `var(--m-tx)` on active buttons and neutral toolbar colors. Therefore neutral active feed chips and neutral compose buttons in this app are broadly correct; copying raw `bg-rose-600`/`text-rose-*` JSX would introduce a regression. Final dark variables are `--m-bg:#1c1c1c`, `--m-soft:#242424`, `--m-line:#2b2b2b` (CSS 12045), with `--m-tx:#f4f4f5`, `--m-mu:#9a9aa3` (CSS 8928). Light `--m-bg:#fff`, `--m-soft:#f4f4f6`, `--m-line:#e8e8ec`, `--m-tx:#101010`, `--m-mu:#80838f` (CSS 6165). AMOLED surfaces use `#000`/`#0b0b0b` and need their own state.

## Real services and behavior to preserve

- `features/feed/services/feed.service.ts:221` uses `meydanApiPage('/timeline?...')`, maps real actors, attachments, quotes, viewer permissions, stats and cursor. Suggestions come from `/squares?verified=1&limit=6`; do not import reference fixtures.
- `features/feed/hooks/useFeed.ts` keeps pagination, auth checks, optimistic rollback and feed/viewer synchronization events. Likes/reposts are PUT/DELETE `/narratives/{id}/{like|repost}`; following uses actor services; join PUT `/initiatives/{id}/join`; delete DELETE `/narratives/{id}`.
- `features/compose/components/ComposeView.tsx:174` POSTs `/narratives` with an idempotency key, `body`, `is_echo`, uploaded attachment IDs, optional `quoted_narrative_id`, approved outlet `media_reflection`. Work mode redirects to real work chat when backend returns `work_id`.
- `features/compose/hooks/useComposeMedia.ts:79` uses real resumable `uploadFile` with abort, retry, upload/processing status and file IDs. `lib/meydan-upload.ts` implements proxy-safe chunks/retries; local blob URLs are previews only and revoked on cleanup. Preserve all these behaviors.
- `features/media/hooks/useViewerPost.ts` uses auth-gated real like/repost/follow/comment operations, idempotent quick replies, stats update events, and preserves failed reply text. `features/media/comments.service.ts` handles cursor comments, real nested replies and comment likes.
- `features/media/components/VideoFeedProvider.tsx` preserves history markers, back closure, media ownership, pause-before-open and PiP exit; selects ReelsView for videos and full-screen image viewer for photos.
- `features/media/components/ReelsView.tsx` loads real video timeline pages, plays only active/near videos, supports keyboard paging, mute state, RTL seeking and long-press speed/rewind/pause. Match geometry without replacing those handlers with appended reference imperative JavaScript.
- Auth/session, native bridge, push and Soketi/Pusher realtime are owned outside the audited presentation surfaces. This report does not claim network success or realtime operation was tested; no requests were sent to publish, upload, delete, follow or like.
